# Hello World Example

This example is a small runnable demo that shows Objective-J-style classes and how they behave once compiled to JavaScript. The repository does not include a full Objective-J compiler; the demo uses a tiny JavaScript shim that mimics the compiled output so you can try the example in any browser.

Files:
- `index.html` — open this file in your browser to run the demo.

How to run:

1. Open `examples/hello/index.html` in your browser (double-click or use a local server).
2. Click the "Say Hello" button to see output produced by the demo class.

This example demonstrates:
- Class definition and instance creation
- Method invocation
- Simple DOM interaction
