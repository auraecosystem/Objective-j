Objective-J Hello Example

This demo shows an Objective-J-style class and the corresponding JavaScript shim that represents compiled output.

Objective-J (pseudo) source

// Objective-J-like source
@implementation Greeter : CPObject
{
    CPString name;
}

- (void)setName:(CPString)aName
{
    name = aName;
}

- (CPString)greeting
{
    return [CPString stringWithFormat:@"Hello, %@!", name];
}

@end

Run the Demo

What this does

The JS shim below implements a small class with setName and greeting methods. This mimics the structure of code generated by an Objective-J compiler so you can interact with it directly.
